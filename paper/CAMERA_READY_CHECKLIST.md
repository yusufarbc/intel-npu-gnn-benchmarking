# IEEE HPEC 2026 Camera-Ready Checklist

## Manuscript

- [x] Uses the `Conference-LaTeX-template_10-17-19` IEEE conference class and includes author names and affiliations.
- [x] Local `IEEEtran.cls` is content-identical to the class in the named template package after line-ending normalization.
- [x] Does not override the template's margins, column widths, font sizes, or float spacing.
- [x] Main text is within the six-page limit; references and acknowledgments may follow.
- [x] NPU is defined in the paper body.
- [x] The mobile client-platform scope is stated explicitly.
- [x] Latency and its relationship to throughput are defined.
- [x] SpDMM terminology is used consistently.
- [x] The `Other` operator category is defined as graph-node composition, not execution time.
- [x] Fixed-shape OGB-derived inputs are distinguished from full-graph execution.
- [x] Quantization, statistical, device-assignment, and package-power limitations are disclosed.
- [x] Unsupported density-correlation and heuristic roofline claims are excluded.
- [x] AI assistance is disclosed in the acknowledgment.
- [ ] Confirm the exact Gemini product/model name in the acknowledgment against the authors' records.
